# 学习通蓝色作业筛选补丁

日期：2026-10-26；在现有 V2.0.1 中定向修改 ai.js，不改变端口、上传接口、前端及本地数据库。

学习通“我的作业”截图：模型返回行级平台、图标颜色和原始状态，提示模型仅提取蓝色且未提交的作业；服务端对带有学习通标记的结果再次筛选。灰色未提交也排除，蓝色已提交/待批阅/已完成排除，颜色或状态未知不猜测。普通通知不执行颜色过滤。保存候选的 evidence 留存筛选依据，并明确这属于 AI 视觉判断，应核对原图。不会删除以前保存的任务。

实测：npm test，30 项全部通过（原有26项＋新增4项）。

新增测试：

1. 根据用户截图构造10行结构化等价样本，保留三项蓝色未提交，分别保留剩余93小时35分钟、22小时35分钟、131小时35分钟，均不自行生成绝对截止时间。
2. 灰色未提交、未知颜色、未知状态、蓝色已提交/待批阅/已完成均不进入候选；全部不符合时返回可读的422错误。
3. 普通通知不按图标颜色排除，保留待批阅与已完成的真实状态。
4. 模拟AI请求验证提示包含学习通规则，仍携带原始图片，并在适配器返回结果前执行二次筛选。

限制：上述为本地逻辑与模拟AI响应测试，没有调用真实 DeepSeek API，也没有替用户更新 GitHub/Render。图标颜色与平台来源仍依赖视觉模型识别，不能宣称已通过真实截图在线识别。未修复之前的AI输出截断问题。仅替换 ai.js 后提交GitHub，Render重新部署后生效。
