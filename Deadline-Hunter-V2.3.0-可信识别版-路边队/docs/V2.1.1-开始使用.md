# V2.1.1 前端修复安全合并版 · 路边队

## 合并内容

基于现有V2.1.0选择性吸收“DeadlineHunter-前端修复(1).zip”的改进，不整包回退到旧V2.0.1。

- 主题在主应用加载前恢复，减少先亮后暗；主题写回不会移除计划字段。
- 浏览器返回/前进或切换页面会关闭旧弹窗，涵盖任务、时间核实、重复确认、删除确认和计划弹窗。
- 取消与“明确跳过核实”分开：切页不再继续保存尚未确认的候选，也不会后台执行删除或重复任务更新。
- 文字通知标题使用首个非空行并限制长度，图片保留文件名。
- 对已经人工确认且确实有日期的事项，时间证据显示“人工填写/已确认”，避免一边已确认一边仍显示待人工核实。没有日期的事项不冒充精确时间；推算精度和依据仍保留。
- 保留V2.1个性计划、任务快照建议、独立进度、日历联动与可选免费推送接入。
- 不采用“本周五过了就自动顺延到下周”的逻辑。不默认将长截图缩至1600像素；继续保留原图和10MB限制。

## 更新到GitHub / Render

1. 在原网页设置先导出JSON备份。
2. 下载并全部解压本次完整项目，将里面的程序文件及子文件夹上传到原GitHub仓库根目录，覆盖同名源码；根目录直接能看到package.json，不要再套一层项目名文件夹。
3. 不上传ZIP本身来代替源码，不上传.env、.env.push.generated、node_modules、截图或私人备份。
4. 保留原Render环境变量，HOST=0.0.0.0；构建npm install --omit=dev，启动npm start。不要随意换有效DeepSeek密钥。
5. 部署最新提交后按Ctrl+F5，网页和后端版本应为2.1.1。已有计划仍在相同网址和相同浏览器里，不需要重建。

本包已经是合并完成的完整项目，不要再用用户提供的旧版七文件包覆盖它。

## Windows本地运行

先停止原服务，备份后覆盖程序文件，保留原.env。在有package.json的项目文件夹执行npm install，然后双击start.bat。继续用相同浏览器及http://127.0.0.1:8790/，Ctrl+F5刷新；不要直接双击index.html。

## 使用与限制

个性计划仍按V2.1.0完整使用方式操作，详见V2.1.0-开始使用.md。
计划不需要Supabase；只有关闭网页后的系统推送需要额外配置免费数据库和独立定时任务。此次合并没有自动替你配置或验证真实设备推送。
AI网络成功返回在测试中使用等价模拟数据，没有真实调用DeepSeek或学习通。旧AI输出截断问题不在此次修复范围内。
