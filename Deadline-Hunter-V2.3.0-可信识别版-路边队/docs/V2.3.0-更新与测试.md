### 年份建议的依据

中国时区Asia/Shanghai。按8月到次年7月的学年给出候选年份；候选若比参考日早90天以上，则顺延一年。它是可修改的建议，无法知道通知真实所属学年，因此始终要求核实并保存参考日期、推断标记与原文证据。跨年1月会建议次年，闰日无效时保留待核实，不造假日期。

仅日期不补23:59；原文有明确时刻才保留时刻。剩余111小时24分钟等仍必须基于完整截图拍摄时间，不能拿当前日期、上传时间、文件修改时间或手机状态栏时刻计算。ICS导出也为未核实任务加标记及TENTATIVE状态。

## 已落地的加分功能

- 七步演示导览：示例回放、遮罩说明、前进与退出。会展示示例候选和已有演示变更，**不是自动调用真实AI的全流程录制，也不会自动接受真实任务变更**。
- 原文句子编号和高亮，显示已核实/推断待确认。
- 多选、拖拽多图排队与Ctrl+V图片粘贴，单批最多20张、单张10MB；逐张核对保存后再点“识别下一张”，不会静默丢弃未保存候选。
- 风险四象限：截止紧迫度×剩余材料量，待确认日期不冒充小时级风险。
- 今天先做什么：最多3条行动建议，优先使用下一步计划或未完成材料；未知耗时明确另计，不把估时当事实。
- 计划预览可逐项编辑1～120分钟，保存并重排保留时长；未知项默认估计30分钟，可修改。每日预算按单段预留和实际估时的较大值校验。超预算不可保存；提供明确增加每日安排/预算或将目标延长2天的按钮，绝不越过已记录截止。
- 静态壳离线：联网成功加载并缓存后，可以断网刷新、查看/修改本地任务。AI识别与问答仍需要联网。

保持现有清晰配色，没有另行添加纸张纹理或装饰印章。重心是数据可靠和可执行流程。

## 提醒与成本边界

页面本地提醒默认关闭，用户在设置里开启；阶段为24小时、12小时、3小时、1小时、30分钟。已确认准确截止、未提交/已逾期且尚未截止的非演示任务才进入计时。弹窗无需云服务；浏览器系统通知需权限及支持。关闭网页后本地计时停止，后台节流、休眠可能延迟。按任务、截止、阶段去重，恢复时只提示最近适用阶段，不补发所有旧阶段。

本版没有替你配置Supabase或Render的VAPID等私密变量。若需要关闭网页后也提醒，仍须按原云推送说明部署并实测。已有云订阅仍显示管理入口。

AI接口单进程默认每IP每分钟8次，所有AI接口合并计数；每分钟全局60次、并发3个。可用AI_RATE_LIMIT_PER_MINUTE调整IP上限。保留15MB请求体上限、10MB图片校验、来源检查；新增非法UTF-8拒绝。**这是成本保护，不是账户鉴权**，直接请求仍可能消耗额度；公开大规模开放仍建议接入登录、个人额度和网关。多实例总额度需在网关统一限制。

备份超过5MB时导出前提示实际体积，含原图；已有导入上限为150MB，请留意过大的备份。

## Windows / GitHub / Render 更新

1. 先在旧版设置导出完整JSON备份，保留原浏览器数据。
2. 将ZIP全部解压。把里面的程序文件及public/docs/scripts等子目录覆盖到旧项目，保留原.env。不要在压缩软件临时目录直接运行。
3. 首次或未安装依赖时，在有package.json的目录运行npm install。双击start.bat，使用原网址和端口，默认http://127.0.0.1:8790/。
4. GitHub上传解压后的**程序文件和子文件夹**到原仓库，覆盖同名文件，不要只上传ZIP，不要套一层版本文件夹；本次必须包含trust.js、public/experience.js和public/experience.css等新增文件。
5. Render保留已有密钥和变量，构建npm install --omit=dev，启动npm start，HOST=0.0.0.0。不要上传.env或node_modules。
6. 部署成功后Ctrl+F5，应显示V2.3.0。PWA会重新联网更新静态缓存；首次访问若尚未收到HTML，Render冷启动画面由平台控制，本应用无法在HTML到达前显示唤醒文案。

同一网址/端口/浏览器保留旧任务。旧的无日期记录不批量改写：重新识别原通知可获得年份建议；已经损坏的中文需要重新输入。
