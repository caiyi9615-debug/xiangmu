## V2.0.1新增与升级方式

- 关闭原 `start.bat` 服务，把新项目文件覆盖到原项目同名文件中；**保留你原来的 `.env`**。交付包不包含私人密钥文件。重新运行start.bat，仍使用8790端口。
- 使用同一浏览器和同一8790地址，旧数据自动兼容；建议先导出JSON备份。不要清除浏览器网站数据。
- 识别后自动弹出一张截图共用的批量时间核实框。剩余111小时24分钟等时长以**你核实的截图完整时间**为基准。没有截图时间时，可以直接填准确截止时间，或跳过按待核实保存。
- 时间统一为Asia/Shanghai。状态栏17:35、文件修改时间、上传时间均不会被自动当作拍摄时间。EXIF仅支持用户自行核实后手动录入基准，本版本不自动提取EXIF。
- 四类截止信息：日期＋时间、仅日期、待核实、无截止时间。仅日期进入月历并以全天ICS导出，不补23:59；只有月日没有年份时保留原文，等待用户补全年份。
- 下周五按下一自然周（周一开始）计算日期；“明天晚上”只解析日期，不推测几点。小时取整等输入保留精度与推算标记。推算值即使人工确认，也保留其推算来源。
- 六种执行状态：未提交、已提交、已完成、待批阅、已逾期、未知。已提交、待批阅与已完成均不触发提交催办；已完成统计只统计真正已完成。
- 候选卡片默认紧凑，详情折叠。批量核实入口可随时重新打开。缺少日期不影响保存；某条标题为空只保留该条待改，不阻止其他正常条目保存。
- 去重综合标题、课程、日期、来源指纹、状态和历史。相似的不同实验、不同章节会被区分。用户自行选择关联更新、新增或忽略，不自动覆盖。
- 每条任务保存时间原文、类型、基准、来源、计算方式、精度、是否推算、是否人工核实、原文证据与当前核实状态。未核实推算不产生确定的小时级逾期警报。

最新测试请看 `docs/时间核验升级测试记录.md`；下方原始V2说明中的完整日期限制和旧测试数量已由本节更新。

## Windows 首次启动

1. 安装 Node.js 20 或更新版本，已经安装过无需重复安装。
2. **右键ZIP → 全部解压**。不要在压缩软件的临时目录内直接运行脚本。
3. 双击 `config-api.cmd`。记事本会打开项目中的 `.env`。
4. 填写你原有的 DeepSeek 密钥，保持模型为支持图片的模型：

   ```ini
   DEEPSEEK_API_KEY=你的密钥
   DEEPSEEK_MODEL=deepseek-flash
   PORT=8790
   ```

5. Ctrl+S 保存，关闭记事本。双击 `start.bat`。
6. 打开 **http://127.0.0.1:8790/**，保持黑色启动窗口开启，可以最小化。

不需要 `npm install` 就能运行。V2沿用V1的Node后端和原生前端技术，以免更换框架增加启动风险；业务逻辑拆分为独立模块。端口使用8790，避免影响V1的8787。

退出：在启动窗口按Ctrl+C，再按Y。修改密钥后需退出并重新启动。可以在“系统设置”发送一次真实连接测试，该请求可能产生少量API费用。

## 主要操作

- 工作台：统计实时读取已保存任务，不填充固定假数字。
- AI通知识别：图片选择/拖拽/预览/替换、文字通知；一次拆出最多20个事项；可编辑、单项删除、单项或批量加入。
- 时间不明确：缺少年份或时刻时，AI应保留 `dateText` 原文并留空完整日期；用户手动确认。日期空缺不进入日历，风险雷达会提示。
- 任务中心：新增、编辑、删除、完成/恢复、分类、搜索、状态筛选、截止日期或优先级排序；点击详情独立勾选材料。
- 月历：切月、回到今天、点击日期/任务、按分类颜色标记；导出标准ICS。
- 通知变更：识别新通知后选择已有任务，点击“比较并创建变更确认”。展示字段前后差异，接受才应用，拒绝不改变任务。相同材料保留勾选状态。旧内容、原文与通知来源保留在历史。
- 风险雷达：已逾期、24小时/72小时、同日集中、材料未备齐、日期待确认；仅在用户提供预计耗时和剩余可用时间后计算工作量风险。
- 系统设置：连接测试、导入/导出JSON、演示数据加载/清除、暗色主题、使用说明。

通知关联候选使用可解释的中文标题二元字组相似度规则，AI负责通知理解与字段提取。相似候选不等于确认匹配；名称不同的事项可人工关联。系统不会自动覆盖任务。

## 数据存储与隐私

任务、来源图片/文字、历史、变更、主题存储在**当前浏览器当前网址的IndexedDB**；无服务器数据库、无账户登录。刷新后保留。不同浏览器、电脑或端口相互独立，切换时使用JSON备份迁移。浏览器清除网站数据会删除记录。

识别草稿在页面间切换保留，但**尚未加入任务的草稿在整页刷新后不会保留**。已保存的任务及原始通知不受影响。

原图以data URL保存在本地数据库，容量取决于浏览器和磁盘。保存失败会提示，不显示保存成功。备份可能包含私人通知，妥善保管。应用不把API密钥传给浏览器；交付ZIP不带 `.env`。

时区：日期按设备当地时间解释，ICS导出转换为UTC（Z）。请在 Windows 使用正确时区，国内通常为UTC+8。

ICS导出当前所有具备完整日期的任务（含已完成）；一个任务优先使用截止日期，没有截止日期时使用活动开始时间。缺少日期的任务跳过。ICS导入日历后不会自动与软件双向同步。

## 常见问题

- 网页拒绝连接：先启动 `start.bat`，不要关闭窗口，不要在服务运行时按Ctrl+C。
- 记事本提示找不到 `.env`：确认完整解压，使用 `config-api.cmd`，同一文件夹应有 `.env.example`。
- “端口已占用”：关闭旧V2窗口，或修改 `.env` 中的PORT并使用新地址。不同端口的浏览器数据不同，先备份。
- “待配置密钥”：确认文件名是 `.env` 而非 `.env.txt`，密钥填在等号后；保存后重启。
- 密钥无效/余额不足：前往DeepSeek开放平台检查密钥和余额。
- 模型不接受图片：使用有视觉能力的 `deepseek-flash`；不要把普通纯文本模型当作视觉模型。
- 图片损坏、超过10MB或格式不支持：重新导出PNG/JPG。HEIC需转为JPG。
- AI超时/空结果/JSON不完整：保留原始输入，点击重试；长通知分段识别。
- 任务修改后接受通知更新提示“任务已修改”：为避免旧变更覆盖新操作，请拒绝旧变更，回识别中心重新比较。
- 手机：界面支持响应式，但默认服务仅监听127.0.0.1，不提供手机跨设备网络访问或云部署。
