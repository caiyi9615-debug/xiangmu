Deadline Hunter V2.4.2 完整项目 · 路边队

这是完整项目，不是补丁。包含前端、后端、源码、测试、Windows启动文件、部署说明。

你已配置过 DeepSeek：
1. 先把压缩包全部解压，不要直接在压缩包里启动。
2. 推荐将里面所有文件覆盖到原项目文件夹，保留原有 .env。
   或者将旧项目的 .env 复制到新文件夹，与 server.js 放在同一层。
3. 如旧服务还在运行，先在旧启动窗口按 Ctrl+C 停止。
4. 双击 start.bat，访问 http://127.0.0.1:8790/，保持启动窗口开启。
5. 网页标题应为 V2.4.2。使用原浏览器和相同网址，已有任务仍保留。

新电脑：需安装 Node.js 20 或更新版本；在项目目录运行 npm install 安装依赖。
新配置请通过 config-api.cmd 填写自己的 DeepSeek 密钥。

此分享包不包含个人API密钥或浏览器里的任务数据。
不需要重新填写已有密钥，只需保留或复制旧 .env。
测试及更新详情：docs/V2.4.2-轻量安排与测试.md
线上Render更新：上传源码文件及子目录，保留Render原环境变量。
