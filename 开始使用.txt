Deadline Hunter V2.4.1 融合优化版 · 路边队

【九项融合改进】
图形四象限、过去18周历史热力图、中文/全角/斜杠日期、多个日期保留正确截止、时长不当时刻、单位核对、具体容量建议、估时来源、识别过滤记录。
入口：更多工具 → 风险雷达 → 展开“图形四象限与历史热力图”。
估时来源在步骤展开后查看；过滤记录在任务详情底部展开查看。
单位出现疑问时，可展开改标题/说明，或对照原文明确核对后保留。
转手动排期同样要核对，手动改步骤名称后旧核对会失效。
容量建议会说明调整数量和预算，经你确认再重新校验，不自动延后截止或占用休息日。
完整说明：docs\V2.4.1-更新与测试.md。

【图一时间核实在哪里】
我的任务 → 日期旁“核实时间”。右上角可以批量核实。
保存过的任务也能直接打开，不必重新上传截图。

【让AI拆解并安排】
1. 任务旁点“AI安排”，或页面顶部点“AI安排任务”。
2. 描述目标，回答AI补问，填写完成日期和每天可用分钟。
3. 可以选择周末休息；其他工作日、节奏和缓冲在高级选项。
4. 查看AI生成的子任务、日期、估时；展开可以修改。
5. 点“保存这份安排”，不用再次填写手动DIY长表单。
6. 点“查看安排”勾选实际完成的子任务，进度自动更新。

【Windows】
先全部解压ZIP。已有旧版先导出JSON备份，覆盖程序文件时保留原.env。
首次安装依赖在项目目录运行 npm install，然后双击 start.bat。
默认 http://127.0.0.1:8790/，保持启动窗口开启。

【GitHub + Render】
上传解压后里面的源码文件及子文件夹，覆盖原仓库同名文件，不只上传ZIP。
保留Render原密钥和变量；HOST=0.0.0.0。
构建 npm install --omit=dev，启动 npm start。
不要上传.env、node_modules或个人备份。
部署成功后按Ctrl+F5，确认显示V2.4.1。

原浏览器、原网址、原端口保留数据。AI需要原有效DeepSeek密钥和网络。
本地提醒需要保持网页打开。详细更新与测试：docs/V2.4.1-更新与测试.md。
