新入口：“问答规划一个项目”或任务旁的“先问我，再安排”。先描述项目，AI追问具体情况，再根据你的回答和时间预算拆解执行步骤；不要求先罗列完整任务。
问答需要原后端有效DeepSeek密钥并会消耗API额度；手动DIY仍可在无AI时使用。

新增：通用大任务、数量/自定义阶段、休息日与每日上限、执行节奏、周汇总、计划预览/拖拽/编辑、剩余内容重排、独立进度条。
不是固定7篇报告，任何1～500项的数量型任务或自定义阶段都可以使用。

【Windows启动】
1. 先右键ZIP，选择“全部解压”，不要在压缩软件临时目录里直接运行。
2. 已有旧版时先导出JSON备份、关闭旧服务。把新版程序覆盖到原目录，保留原.env。
3. 在有package.json的项目文件夹打开终端，执行一次 npm install。
   本版保留可选推送依赖，需要这一步；你已安装Node，无需再次安装。
4. 双击 start.bat，默认打开 http://127.0.0.1:8790/ 。保持启动窗口开启，可最小化。
5. 原浏览器、原网址和原端口保留旧任务。Ctrl+F5刷新后应看到V2.3.0。
6. AI识别继续使用原有效DeepSeek密钥；只用本地任务与计划不要求AI密钥。

【使用个性计划】
推荐先点“问答规划一个项目”，回答问题后生成建议，采用建议后进入原排期预览，再确认保存。只有明确采用才创建项目，问答过程中不会自动保存。
先创建/识别并保存任务 → 在任务行或详情点“制定个性计划” → 自行填数量/单位或阶段 → 设置日期、节奏、休息日 → 生成预览 → 修改并确认保存。
完成子任务后手动勾选；计划100%不自动等于已提交，材料清单也独立计算。
没按计划完成时重排剩余内容，已完成和固定安排保留，保存前显示差异。

【GitHub + Render更新】
上传本包程序文件及子文件夹，覆盖原仓库同名源码。不要只上传ZIP。
保留Render环境变量，HOST=0.0.0.0；构建 npm install --omit=dev，启动 npm start。
不要上传.env、.env.push.generated、node_modules或个人备份。
本次计划功能不需要Supabase；可选免费后台推送仍需另外配置才会启用。
