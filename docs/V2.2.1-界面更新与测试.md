# V2.2.1 界面更新与测试 · 路边队

日期：2026-10-26。继续修改原项目，保留V2.2.0问答规划、手动DIY、独立进度条、图片上传、学习通筛选、时间证据和可选推送。

## 界面变化

- AI识别页：左右区域更均衡，上传区缩短，输入说明降低视觉干扰；结果区有完整的空状态与识别等待状态，不显示虚假进度百分比。
- 核实弹窗：默认显示任务标题、课程、原文时间、计算结果、当前状态和独立核实勾选。点击任务展开修改，支持展开/收起全部。
- 日期类型切换后只显示对应输入框；“待核实”仍可直接填准确截止时间，“无截止时间”隐藏日期输入。折叠后摘要即时反映修改。
- 弹窗标题栏和底部按钮固定，中间内容滚动。手机采用全屏面板，日期与选择输入为16px；仍能跳过核实保存。
- 深色与浅色都使用原设计配色。保持原浏览器数据库名称与结构。

## Windows 更新

1. 在旧版设置里导出JSON备份。关闭旧启动窗口。
2. 将ZIP“全部解压”。用新程序文件覆盖旧项目同名文件，保留原来的`.env`；不要在压缩软件里直接启动。
3. 在有`package.json`的目录打开终端，首次运行或依赖未安装时执行`npm install`。已有依赖无需重复安装。
4. 双击`start.bat`，保持窗口开启。打开原来的网址，默认`http://127.0.0.1:8790/`，按Ctrl+F5，应显示V2.2.1。
5. 继续用原浏览器、原端口和原网址；换网址不会自动搬运本地任务。

## GitHub / Render 更新

将解压后项目目录**里面的程序文件和子文件夹**上传到原仓库，覆盖同名文件。不要只上传ZIP，也不要再套一层版本文件夹。须同时更新`public/app.js`、`public/review.js`、`public/index.html`与新增的`public/capture.css`。

保留Render已有的密钥和其他环境变量。原Node服务配置继续使用：构建`npm install --omit=dev`，启动`npm start`，`HOST=0.0.0.0`。不要上传`.env`、生成的私密推送配置或`node_modules`。部署成功后Ctrl+F5，应显示V2.2.1。
