# V2.2.0 问答式项目规划版 · 路边队

## 核心变化

现在不要求你先罗列全部子任务：提供项目目标 → AI先追问具体情况 → 你回答并确认时间预算 → AI拆解剩余工作与产出 → 系统校验休息日、预算和截止 → 你预览修改并确认计划。

可用于学习、复习、作品、比赛或其他项目，不限定为报告。AI追问由项目上下文生成，不是固定“7篇报告”模板。

## 怎么开始

### 新项目

工作台或任务中心点击“问答规划一个项目”。

1. 写名称和希望达成的结果，可以只描述想法，不必先写步骤。
2. 明确截止日期可填写并勾选已确认；未知可以留空，不猜年份/时刻。
3. 点“让AI先问我几个问题”。AI根据具体项目追问2～5项，例如交付标准、已有基础、资源、能力、困难等。已经明确的内容不要求重复回答；可用时间和休息日会在下一步独立确认。
4. 按实际情况回答。不知道可以写“请给建议”，AI估计和假设会显示出来。
5. 确认开始/目标日期、每天可用分钟、每段专注分钟、工作星期、额外休息日、检查缓冲。选择“根据我的回答建议”可由AI建议节奏；明确选择的节奏不会被自动覆盖。
6. 点“根据回答生成执行方案”。查看每步具体做什么、完成标准、所属阶段、估计时长及排期依据。
7. 回答或硬限制改变后，旧结果会失效，需要重新生成。
8. 点“创建项目并编辑排期”：这一步明确创建一个普通主任务，但计划还没有保存。
9. 进入原有排期预览，仍可编辑日期、固定、拖动、调整步骤。确认后点“确认保存此计划”。

### 已有但尚未制定计划的任务

任务行/详情点击“先问我，再安排”，已有信息会预填。本次不会改写原通知截止信息。AI建议仍须进入排期预览确认。

### 已经有计划的任务

继续使用“查看计划 → 修改/重排剩余计划”，保留已完成内容与固定日程。当前问答入口不会直接覆盖已有计划，避免把旧进度清空。需要基于完全新范围重新问答时，应另建项目或先备份后自行明确删除旧计划。

## AI和规则分别负责什么

- AI：理解目标和回答、提出针对性问题、拆解尚未完成的工作、建议具体动作和产出、估计时长、解释假设。
- 本地/后端规则：检查预算、休息日、日期范围、容量；不能让AI擅自增加每日可用时间、延后目标、减掉缓冲或占用已确认的休息日。
- 回答中额外提出的休息星期/日期可由AI建议加入，但只会收紧已确认限制；建议也要人工核对。如果你只想周末做，应在可用星期中明确选择周末，避免和默认工作日限制冲突。
- 具体日程按日安排，不是精确到几点的日历预约；每天按“单段上限×安排段数”保守预留，不假装已经优化了所有项目的真实工时。
- 排不下会保留工作量并报错，不通过删掉必需步骤伪造可行。你可以修改时间/范围重新生成，或进入预览明确调整；有冲突时不能确认保存。

## 进度与估计

AI建议的时长不等于真实耗时，尤其复杂项目请留缓冲；它不了解你未提供的信息。请核对是否漏掉工作、误判基础或安排了你已经做过的内容。
工作量进度按实际勾选的执行步骤计算，不随日期增加，不等于工时完成率，也不自动变成“已提交”。所有AI步骤初始都是未完成。
问答依据、假设、执行说明和估计会随已确认计划保存在原浏览器数据库并进入备份，不上传到提醒云数据库。未采用方案或关闭问答不会自动创建任务。
AI方案采用后创建了主任务，但如果你随后取消排期预览，这个主任务会保留为尚未制定计划的普通任务；不会假装排期已保存。

## 配置与费用

沿用后端已有有效DeepSeek密钥，不需要另申请一种API。通常先一次请求生成问题，再一次请求生成方案；重试或重新生成会额外消耗原API额度。
项目描述和回答会发送到DeepSeek，不要填写密钥或隐私资料。未配置、网络失败或额度不足会明确提示，项目描述/当前回答保留在当前页面，可重试或改用手动DIY。
没有云端任务账户同步；个人数据仍按原网址、原浏览器保存。不要把测试截图或备份公开上传。

## GitHub / Render更新

先在原网页导出备份。解压完整项目，把里面的源码与子文件夹上传到原GitHub仓库根目录，覆盖同名文件，不多套一层目录。
本版同时新增根目录advisor.js和public/advisor-ui.js，不能只更新前端或只更新ai.js，否则问答接口不存在。
保留原Render环境变量；HOST=0.0.0.0，构建npm install --omit=dev，启动npm start。部署后Ctrl+F5，应看到V2.2.0。
不要上传.env、.env.push.generated、node_modules、个人截图或备份。

Windows本地：备份后停止旧服务，覆盖程序但保留.env，执行npm install，再双击start.bat，继续原8790地址。不要直接打开index.html。
既有免费后台通知仍需额外配置；本版没有自动替你配置Supabase或验证真实手机推送。

## 技术与测试边界

新增问答接口使用DeepSeek JSON输出并显式关闭默认思考模式；总90秒预算内对截断/不完整JSON最多重试一次，不保存半份结果。这是新接口设置，不是对旧图片识别接口输出截断问题的全面修复。
参考官方说明：https://api-docs.deepseek.com/guides/thinking_mode/ 、https://api-docs.deepseek.com/guides/json_mode/
实际AI提问质量、项目拆解与耗时估计需用你的项目在线验证。本次没有使用你的真实密钥调用AI，不声称已经连接学习通或保证项目能按时完成。
