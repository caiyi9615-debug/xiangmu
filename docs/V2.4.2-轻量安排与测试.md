# V2.4.2：先给草案，少填信息

路边队 · 2026-10-31。基于现有 V2.4.1 修改；此版本集中改善 AI 安排入口，不代表整套 V2.5 产品建议已经全部实现。

## 怎么使用

已有任务：我的任务 → AI安排 → 检查带入的日期和时间偏好 → 生成安排草案 → 确认保存。

不再默认生成一份问卷。任务名称、原要求与截止信息自动带入。首次建议每天45分钟、周末休息；可直接修改。勾选“保存安排时记住习惯”后，时间、每段专注时长、工作日、节奏和缓冲会在下一次复用。任务日期、当前进展和本次额外休息日期不会变成通用偏好。

新任务可只填写目标，额外要求可空着。有缺失且真正影响方案的关键事实时，AI可以返回最多两个问题。希望先详细沟通的用户，可展开“其他方式”选择“我想先聊清楚”；手动安排也保留。

未知截止：明确填写计划范围，或点击“先排未来7天”。这一操作只安排工作，不会给原任务填入假的截止日期。已记录的截止不会因为规划而延后。

草案明确展示估时和假设，展开子任务可以改名称、日期、分钟与说明。休息日、容量、单位核对继续校验。生成草案不保存任务，也不会自动完成或提交；最后确认才同时保存任务、计划与选择记住的偏好。

## Windows 原地升级

本次已同步更新桌面原来的 `Deadline-Hunter-V2.4.0-简洁AI安排版-路边队` 文件夹，名称沿用，内容版本为2.4.2。已有 `.env` 原样保留，无须重新输入 DeepSeek 密钥。

双击原文件夹里的 `start.bat`，打开 http://127.0.0.1:8790/ 。保持服务运行。已有任务在同一浏览器、同一网址下保留；不要清除网站数据。

ZIP分享包不包含个人密钥、原图或本地任务数据。使用ZIP升级时先完整解压；保留原 `.env`，覆盖程序文件。全新电脑需安装Node.js 20或更新版本，并在项目目录运行 `npm install`。浏览器标题应显示V2.4.2；若旧页面尚未更新，先重新加载。

GitHub/Render：覆盖仓库源码文件和子目录，保留Render已有环境变量。此交付未代替用户更新线上部署。
