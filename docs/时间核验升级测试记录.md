# V2.0.1 时间核验与状态升级测试记录

基于现有Deadline Hunter V2原地维护，队伍：路边队。测试日期：2026-10-25，默认校园时区Asia/Shanghai。

## 测试分层与真实边界

- 业务/HTTP自动化使用Node内置test runner：`npm test`。
- 浏览器使用本机Edge与Playwright；在隔离浏览器数据库运行，不修改用户日常浏览器的任务。
- 使用用户提供的实际作业列表截图验证文件选择、解码、预览与拖拽。成功识别响应采用按截图逐行构造的等价数据，通过实际后端输出校验器后再注入浏览器请求。
- **本次没有使用有效密钥执行真实DeepSeek在线视觉/文字识别。** 新AI提取提示和输出校验已经实现，但不能将模拟响应通过描述成真实AI识别通过。缺少密钥错误路径实际访问本地后端验证。
- 当前32项浏览器场景通过；Node测试覆盖原9项和新增17项，共26项。最终以包内实际执行日志为准。

## 核心逻辑验证

- 年份、月份、日期、时刻校验，不可能日期拒绝。
- 只有日期不补23:59；原文缺年份不补系统当前年。
- AI即使返回23:59，但原文没有时刻，也会移除模型补出的时刻。
- AI不能自设“用户已确认”或伪造截图基准；手机状态栏、上传/修改时间不会被读取为基准。
- 剩余时长整小时显示标明取整精度，所有时长推算都保留“推算值”标记。
- 活动开始单独存储，不转成截止日期。
- 已完成、已提交、待批阅不产生待提交催办或材料预警。
- 原始平台“已逾期”与基于已核实时间计算的逾期分开说明；未核实推算不假装确定过期。
- 仅日期导出为 `DTSTART;VALUE=DATE`，而非假设23:59。
- 无截止、待核实都能独立保存。
- 去重按多信号推荐，同课程不同实验报告不误合并；不同章节按编号区分。
- 旧版todo/done数据自动兼容为未提交/已完成，保留原任务ID和来源。

## 浏览器实际执行场景

1. 用户实际截图选择、解码与预览。
2. 拖拽替换图片。
3. 真实后端无密钥时显示503原因，不假装成功。
4. 一张八任务截图只弹一轮统一核实，不预填系统时间。
5. 一次填写截图时间，三项倒计时统一计算。
6. 紧凑卡片默认折叠，展示课程、时间、状态与来源。
7. 已完成、待批阅、未提交正确分开存储。
8. 时间原文、计算方法、基准、精度、核实状态持久保存。
9. 刷新后所有任务与新增字段保留。
10. 工作台完成数只计已完成，待批阅不进待行动。
11. 已完成、待批阅不出现在风险催办列表。
12. 洛杉矶浏览器时区下日历中国日期不偏移。
13. 按待批阅筛选。
14. 相同截图再次上传显示已有/新结果，忽略不新增。
15. 用户选择关联更新后更改日期/状态并保留历史。
16. 仅日期、下周五、明晚可保存，不补时刻。
17. 仅日期进入月历并下载全天ICS。
18. 手动不填时间仍能保存；状态修改同步。
19. 无AI服务也能手动新增任务。
20. JSON备份包含时间证据。
21. 明暗主题切换。
22. 新模型备份恢复。
23. 通知变更拒绝时旧日期不变。
24. 通知变更接受后保留旧内容和时间证据。
25. 接受变更后月历同步。
26. 搜索与删除记录。
27. 手机390px时间弹窗、跳过核实后保存及无全页横向溢出。
28. 无页面运行时异常。
29. 旧版已完成任务迁移后工作台统计正确。
30. 发现重复时用户可明确选择保留为新任务。
31. 一项标题清空不会阻止同批正常任务保存。
32. 手机弹窗直接填写准确截止时间，无需拍摄基准；未知状态可人工选择。

## 修复中发现的问题

- 同课不同实验仅因“实验报告”通用词而被推荐为重复：现在要求更高标题特异性，章节不同直接排除。
- 活动时间在时间类型分类时落入“仅日期截止”：调整分类顺序并增加回归测试。
- 保存一条无效标题阻止整批：改为保留无效条目，正常条目继续保存。
- 修改执行状态后只改旧todo/done字段：现在同步更新executionStatus与旧兼容状态。
- 新截图不会沿用上一张截图时间；每张截图的基准单独核实。
- 手机重复点击当前页面导航时菜单不收起、遮挡识别按钮：现在点击任意导航链接都会收起菜单。

## 已知边界

- 真实模型对图片的任务召回、课程文字和平台状态提取质量需要配置有效密钥后人工核对。本次未宣称已完成在线AI验收。
- 中文自然时间解析限定支持今天/明天/后天、本周/下周指定星期、月底与数字剩余天/小时/分钟；其他表达保留待核实，不猜测。
- “晚上”等时段不转换为具体钟点；仅月日不补年份；EXIF不自动解析。
- 同时保留多个来源时，单条任务只维护当前生效的时间证据，历史记录保留前后版本。
- 本地任务和数据随原浏览器/8790网址保存，不提供跨设备同步或后台推送。
- 未实际导入Outlook/Apple Calendar；ICS做格式、字节折行、日期及UTC转换测试。
- 未在真实手机硬件/Safari/Firefox上测试；手机指Edge移动视口。
- 尚未保存的识别草稿整页刷新会丢失；已保存任务不丢失。

